# 角色图片放置说明

## 如何添加本地角色图片

1. **图片命名格式**：按照 `角色名字.png` 的格式命名
   - 例如：`火影忍者-鸣人.png`、`海贼王-路飞.png`、`龙珠-孙悟空.png`

2. **图片尺寸**：建议使用正方形图片（如 300x300 像素）

3. **图片格式**：支持 PNG、JPG、JPEG、GIF、WebP 格式

4. **放置位置**：直接将图片放在 `images` 文件夹中

## 示例

如果你的角色列表是：
```python
ssr_characters = [
    "火影忍者-鸣人",
    "海贼王-路飞",
    "龙珠-孙悟空"
]
```

那么你需要准备以下图片：
- `images/火影忍者-鸣人.png`
- `images/海贼王-路飞.png`
- `images/龙珠-孙悟空.png`

## 注意事项

- 如果没有找到本地图片，系统会自动生成默认图片
- 图片文件名必须与角色名字完全一致（包括空格和符号）
- 建议使用清晰、美观的角色立绘图片

## 如何获取角色图片

1. 从官方网站下载角色立绘
2. 使用搜索引擎搜索角色图片
3. 截图游戏或动画中的角色画面

添加本地图片后，重新运行 `start.py` 即可看到效果！
